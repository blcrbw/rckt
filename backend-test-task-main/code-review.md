## Структура
- **Domain**
  - **Entity** - Классы сущностей
  - **Factory** - Классы фабрик
  - **Repository** - Интерфейсы репозиторие
  - **Service** - Интерфейсы сервисов
- **Application**
  - **DTO**
  - **Service** - классы реализаций сервисов
  - **Use Cases** - классы хэндлеров
- **Infrastructure**
  - **Http** - классы http взаимодействия
  - **Persistence** - классы реализации репозиторией и подключения к средствам хранения
- **Presentation**
  - **Controller** - классы контроллеров
  - **View** - классы отображения данных
## Логика взаимодействия слоев
- Controller принимает сырой запрос и читает пользовательские данные. выполняет первичную валидацию
- Создается DTO Request
  - Выполняется валидация входных данных
- Вызывается Use Case handler
  - Вызывается Service
    - Происходит взаимодействие с репозиториями
    - Подготавливаются данные для ответа
  - Данные упаковываются в DTO Response
- Извлекаются данные из DTO Response
- Данные передаются во View для формирования ответа
- Возвращается ответ
